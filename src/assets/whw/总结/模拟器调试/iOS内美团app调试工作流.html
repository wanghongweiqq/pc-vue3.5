›
📐
计算 Bezel

5
坐标换算 · 关键桥接
截图像素坐标 → 屏幕逻辑点坐标（CGEvent 所需）
换算公式
scale_x = screenshot_width(px) / content_area_width(pt)
                          — Retina 屏通常 ≈ 3.47

screen_x = WIN_X + BEZEL_LEFT + pic_x / scale_x
screen_y = WIN_Y + BEZEL_TOP  + pic_y / scale_y
坐标来源 单位 用途
OCR 输出 pic_x/pic_y 像素 px 截图内文字位置
CGWindowList WIN_X/WIN_Y 逻辑点 pt 窗口在屏幕上的位置
CGEvent 点击坐标 逻辑点 pt 鼠标事件目标位置
Cmd+Shift+4 拖选数字 逻辑点 pt 直接传 CGEvent，无需除 scale
Preview 截图内坐标 像素 px 需除以 scale 再传 CGEvent
